{# SmartVA run archive — same bucket, smartva_runs/ prefix #}
SmartVA run archive
SmartVA run directories are an operational artifact layer: nothing in the app reads one after its results are saved. They are archived to the same private bucket under the smartva_runs/ prefix and removed from the VM only after every file is verified there. These objects are never presigned and never served.
