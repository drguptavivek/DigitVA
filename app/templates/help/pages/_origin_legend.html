What do "Origin", the rules and the other columns mean?

WHO's 2022 verbal autopsy cause list says which ICD codes belong to each VA cause, mostly as code ranges (for example 1B40-1B42). Origin says where a code's VA cause comes from.

WHO
WHO's list gives the code to this cause and to no other. Nothing to decide.
WHO (overlap resolved)
WHO's list gives the code to two or more causes — usually because its ranges overlap. A code can report to only one cause, so one of WHO's choices was taken by the rule shown under the badge (rules below). The other cause WHO listed is shown as also claimed by.
Not in WHO's list
A code coders can select that WHO's list happens not to cover, so a cause had to be assigned. The reason is shown under the badge — for example it follows its ICD-10 equivalent, or clinical review placed it (diabetic ketoacidosis under Diabetes).
Not a cause of death
Never selectable. WHO's cause list does not include these codes at all — for example ICD-11's traditional medicine, functioning and "factors influencing health status" chapters. They are mapped to Unknown cause only so that no record can ever go unreported.
Differs from WHO
WHO's list covers the code but gives it to a different cause, and the expert review deliberately chose otherwise. The reason is shown under the badge, for example viral infections of the central nervous system reported as Meningitis/encephalitis to match ICD-11.
Unmapped
No VA cause yet; such a code would report as unmatched.

The rules, with examples

Narrowest range wins
The code falls inside two WHO ranges; the range covering fewer codes is the more specific statement, so it wins. Example: 1B40 Acute rheumatic fever is inside the cardiac range 1B40-1B42 (VAs-04.99 Other and unspecified cardiac disease) and inside a much broader infectious-disease range (VAs-01.99); it reports as cardiac.
Specific code beats range
WHO names the code on its own for one cause and only inside a range for another; the named code wins. Example: A33 Tetanus neonatorum is named for VAs-10.05 Neonatal tetanus and also sits inside the general tetanus range (VAs-01.08); it reports as neonatal tetanus.
WHO lists the same code for more than one cause
WHO gives exactly the same code to two causes and the code itself cannot tell them apart. Example: ICD-10 P95 Fetal death of unspecified cause is listed for both Fresh (VAs-11.01) and Macerated (VAs-11.02) stillbirth; ICD-10 has no way to separate them and DigitVA does not invent codes, so P95 reports as Macerated. ICD-11 separates them (KD3B.1 intrapartum, KD3B.0 antepartum).
Transport split
WHO prints one ICD-11 range, PA00-PA5Z, for both Road traffic (VAs-12.01) and Other transport (VAs-12.02) and says the split is whether the death was a road traffic accident. The ICD-11 code says so: traffic events (PA0x) are road traffic; non-traffic, railway, water and air events are other transport. Where it is unknown whether the event was traffic, DigitVA follows WHO's own ICD-10 rule — assume traffic for vehicle occupants and cyclists, not for pedestrians or off-road vehicles.
Expert review decision
A choice between WHO's overlapping causes made by expert review and recorded with its reason. Examples: maltreatment by others (PJ20-PJ2Z) reports as Assault; chronic ischaemic heart disease (BA5x) reports as Acute cardiac disease, matching how ICD-10 I25 is reported.

Other columns

Coding: Selectable / Not selectable
Whether a coder may choose this code as a cause of death (age and sex rules still apply per death). Not selectable codes still carry a VA cause so that any record already using them reports correctly.
Policy review: Reviewed / Unreviewed
Whether a person has confirmed the code's selectability. ICD-11 is currently an Unreviewed draft built from WHO's list, awaiting expert review.
