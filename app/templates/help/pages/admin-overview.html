Administration Panel Overview

The DigitVA administration panel at /admin is the central hub for managing master data, users, access grants, ODK connections, and project configuration. It is an HTMX-driven single-page interface where selecting a panel from the left sidebar dynamically loads its content into the main area without a full page reload.

Accessing the Admin Panel

The admin panel is available to authenticated users who hold the admin or project_pi role. Not all panels are visible to every role. After the page loads, a JavaScript bootstrap call determines the user's role and reveals or hides panels client-side.

Panel Layout

The interface uses a Bootstrap-based two-column layout. The left sidebar lists all panels the current user is authorized to see. Clicking a panel name loads its content into the right-hand content area using HTMX partial responses. The active panel is highlighted in the sidebar.

Admin-Only Panels

The following panels are restricted to users with the admin role:

  • ODK Connections — manage ODK Central server connections, encrypted credentials, and connection health. See ODK Connections.
  • Users — create, deactivate, and reset user accounts; assign coder languages.
  • Sites — manage site master data. See Sites.
  • Projects — create and configure projects. See Projects.
  • Languages — manage canonical languages and ODK alias mappings.
  • COD Buckets — edit COD reporting schemes and ICD-to-disease remapping.
  • ICD-10 Browser — browse the ICD-10 code hierarchy with local policy curation.
  • Field Mapping — configure how ODK fields are displayed in the coding form.
  • Data Sync — trigger, monitor, and troubleshoot ODK data sync. See Sync Behavior.
  • Activity — view a workflow activity log of state-changing actions.

Project-PI-Accessible Panels

Users with the project_pi role can access the following panels, scoped to their own assigned project:

  • Access Grants — manage user-to-project/site role assignments.
  • Project Sites — map sites to projects. See Project-Site Associations.
  • Project Forms — configure per-site ODK form mappings and SmartVA settings. See Project-Form Settings.
  • Project PIs — manage PI assignments scoped to a project.

CSRF Protection

All state-changing routes in the admin panel enforce CSRF protection via the X-CSRFToken request header. This applies to both traditional form submissions and HTMX-driven partial updates.
