Overview

The Data Manager Dashboard at /data-management is the primary workspace for data-quality triage and operational review of verbal autopsy submissions. It provides scope-based visibility into submissions before and after coder allocation.

Dashboard visibility is grant-scoped, not allocation-based. You see all submissions within your assigned project or project-site scope, regardless of whether you have previously worked on them.

How Scope Is Determined

Your dashboard visibility depends on your data-manager grants:

Grant Scope What You See
Project All submissions across every site in that project
Project-Site Only submissions belonging to that specific project-site pair

If you hold multiple grants, your visible scope is the union of all grants. The dashboard and all sync actions enforce this scope boundary.

KPI Summary Cards

The top of the dashboard displays summary cards with key operational metrics. All card counts reflect your current filter selection.

Card Meaning
Submissions Total submissions in scope matching current filters
Pending Coding Coder-actionable submissions only: ready_for_coding, coding_in_progress, coder_step1_saved
SmartVA Queue Submissions waiting for SmartVA processing
Coded Submissions with a finalized coding outcome
Flagged Not Codeable Submissions marked as not codeable (by coder or data manager)
ODK - Has Issues Submissions with ODK Central review state set to hasIssues
SmartVA Missing Submissions with no active SmartVA output (includes consent-refused rows when filtered)
Pending Coding does not include pre-coding pipeline states such as screening_pending, attachment_sync_pending, or smartva_pending. These are separate operational queues.

Clicking certain cards applies the corresponding filter directly to the submission table.

Submission Table

The submission table loads lazily through the paginated API. It displays all submissions in your scope with the following columns:

  • Masked submission ID
  • Project / Site
  • Submitted date
  • Workflow state
  • Coded-on / Coded-by (for coded submissions)
  • ODK review state (mirrored from ODK Central)
  • ODK sync issue state (e.g., missing_in_odk)
  • SmartVA status
  • Attachment count
  • Optional columns: project, collector, flagged-at timestamp

SmartVA Status Values

Status Meaning
Available An active SmartVA result exists and did not fail
Failed An active SmartVA result exists with outcome failed
Ineligible Workflow state is consent_refused; SmartVA is not required
Missing No active SmartVA result exists for this submission

Filters

The filter panel opens as an offcanvas sidebar from the right edge of the dashboard. Available filters include:

  • Project
  • Site
  • Language
  • Submitted from / to (date range)
  • ODK status
  • SmartVA status
  • ODK sync status
  • Workflow state
  • Free-text search
  • Optional column toggles
Filter state is stored in the URL, making it bookmarkable. You can share a filtered dashboard view by copying the browser URL. Filters persist across page reloads.

Workflow Guide

The dashboard includes a workflow guide with a Mermaid diagram that shows the actual workflow states, including pre-coding pipeline states:

  • screening_pending
  • attachment_sync_pending
  • smartva_pending
  • ready_for_coding
  • coding_in_progress
  • coder_step1_saved
  • coder_finalized
  • recode_pending
  • and subsequent states

The workflow distribution donut chart also reflects these real states. Clicking a donut segment filters the table to that exact workflow state.

Coder Daily Statistics

A coder-by-day output table shows first-pass coding volume. Rows are coder names; columns cover the last 7 calendar days (inclusive of today, using your timezone). Only coder_finalized events are counted. recode_finalized events are excluded.

This table responds to the same dashboard filters as the main grid and KPI cards.

Exports

The Export dropdown in the dashboard header provides these downloads:

Export Content
Export Data Current workflow/coding state and filtered ODK payload data
SmartVA Input Data Cleaned SmartVA preparation input for active payloads
Results Active SmartVA summary result fields
Likelihoods Raw active SmartVA likelihood rows
Coded COD Snapshot One row per submission with coder, reviewer, authoritative, and SmartVA COD fields, plus NQA question details
All exports respect your current dashboard filters and scope. Exports omit fields marked as PII in the field mapping. SmartVA exports do not include the full raw VA payload. CSV files are UTF-8 with BOM for Excel compatibility.

Recent Sync Results

A collapsed-by-default panel shows recent sync runs you initiated, including the form target, start time (in your timezone), run status, records added/updated, and the latest progress or error entries.
