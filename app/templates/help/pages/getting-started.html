What is DigitVA?

DigitVA is a web-based platform for verbal autopsy coding. It supports the full workflow from intake of verbal autopsy submissions collected via ODK, through cause-of-death (COD) coding using ICD-10, to review, reporting, and site-level quality dashboards.

The platform is used by coders, reviewers, site investigators, data managers, project leads, and system administrators. Your role determines which parts of the system you can access.

Core Workflow

  1. Sync — Verbal autopsy submissions are synced from ODK Central into DigitVA.
  2. Preprocessing — Attachments are downloaded and SmartVA processing runs automatically.
  3. Coding — Coders are allocated submissions and work through structured categories to determine a cause of death.
  4. Review — Reviewers perform secondary coding on a sample of finalized cases.
  5. Reporting — Site PIs and project leads view dashboards with KPIs, workflow outcome counts, and coder participation data.

First Steps After Login

When you log in, DigitVA automatically redirects you to the landing page for your primary role:

Your Role Landing Page What You See
Admin Admin Dashboard User management, projects, sites, integrations, sync controls
Coder Coder Dashboard Available forms, coding history, start coding button
Reviewer Reviewer Dashboard Eligible cases for secondary coding
Data Manager Data Manager Dashboard Submission browse, sync status, triage controls
Site PI Site PI Dashboard Site-level KPIs, workflow outcomes, coder participation
Tip: Your landing page is set automatically based on your role grants. If you hold multiple roles, the system uses your primary landing page. You can access additional dashboards if your role grants allow it.

Onboarding Flow for New Users

If you are a new user, the onboarding sequence is:

  1. An administrator creates your account with your email address.
  2. You receive a verification email. Click the link to verify your address.
  3. After verification, you are redirected to set your password.
  4. On first login, you may be asked to accept terms and conditions before proceeding to your dashboard.

See the Email Verification and Password Reset help pages for details on each step.
