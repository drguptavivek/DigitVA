# ICD Cause Group Mapping Archive

This folder holds archived XLSX and JSON files moved out of
`docs/icd-causegrp-mappings/` to reduce confusion between:

- active migration-artifact sources used by the application
- current working inputs still referenced by scripts or docs
- older exports, backups, overlap reports, and ad hoc helper files

The active built-in COD bucket reset-default source of truth remains the
frozen files under `docs/icd-causegrp-mappings/migration-artifacts/`.
